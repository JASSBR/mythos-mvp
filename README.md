# MYTHOS

Plateforme de jeu narratif multijoueur propulsee par IA.

## Stack

- **Frontend** : Next.js 16, React 19, TypeScript, Tailwind CSS, shadcn/ui
- **Backend** : NestJS 10, Prisma 5, PostgreSQL, Socket.IO
- **IA** : Claude API (Anthropic) avec streaming narratif
- **Deploiement** : Vercel (frontend) + Render (backend) + Neon (PostgreSQL)

```bash
# Backend
cd backend && npm install && npm run start:dev

# Frontend
cd frontend && npm install && npm run dev
```
